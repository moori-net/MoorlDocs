## Add-ons

Dieses Plugin bietet eine Vielzahl erweiterbarer Services, die von kostenpflichtigen Add-ons oder durch Ihre eigenen individuellen Erweiterungen genutzt werden können. Zu diesen Services gehören:

1. Formular-Aktionen, wie beispielsweise das Versenden von E-Mails
2. Formular-Typen, wie beispielsweise Produktanfrageformulare
3. Element-Typen, wie beispielsweise USt-IdNr.-Felder mit Validierung
4. Element-Auswahlen, wie beispielsweise Länderauswahlfelder

Die folgenden kostenpflichtigen Add-ons sind im Shopware Community Store verfügbar:

- [Classic Add-On](https://store.shopware.com/de/search?search=MoorlFormsClassic) - Eine große Sammlung nützlicher Funktionen und zusätzlicher Formularelemente
- [Exit-Intent Popups Add-On](https://store.shopware.com/de/search?search=MoorlFormsPopup) - Zeigen Sie Formulare als Popups mit vielen Auslöseoptionen an
- [Slides Add-On](https://store.shopware.com/de/search?search=MoorlFormsSlides) - Teilen Sie große Formulare in mehrere Schritte auf
- [Kundenformulare Add-On](https://store.shopware.com/de/search?search=MoorlFormsCustomer) - Erweitern Sie die Kundenregistrierung und erstellen Sie kundenspezifische Formulare
- [Produktkonfigurator Add-On](https://store.shopware.com/de/search?search=MoorlFormsCustomProducts) - Produktkonfigurator mit individueller Preisberechnung
- [Bestellung Add-On](https://store.shopware.com/de/search?search=MoorlFormsOrder) - Ergänzen Sie zusätzliche Felder und Informationen im Checkout- oder Bestellprozess
- [Produktanfrage Add-On](https://store.shopware.com/de/search?search=MoorlFormsProduct) - Regelbasierte Produktanfrageformulare

## Große und komplexe Formulare erstellen

Mit diesem Plugin erstellen Sie sowohl einfache als auch hochkomplexe Formulare direkt in Shopware 6. Die Formularstruktur basiert auf einem verschachtelten Baumsystem, wodurch auch umfangreiche Formulare klar und effizient organisiert werden können. Sektionen, Bereiche und responsive Zeilen helfen Ihnen dabei, strukturierte Layouts aufzubauen, die auf unterschiedlichen Geräten und Bildschirmgrößen zuverlässig funktionieren.

Für verschiedene Anwendungsfälle steht Ihnen eine große Auswahl an Formularelementen zur Verfügung. Jedes Element kann detailliert konfiguriert werden, darunter minimale und maximale Zeichenlängen, Datumsbereiche, minimale und maximale Auswahlgrenzen, Zuordnungen zu Datenbankfeldern sowie das responsive Verhalten. Optionaler Captcha-Schutz, einschließlich Kompatibilität mit Google reCAPTCHA, unterstützt Sie dabei, Ihre Formulare vor unerwünschten Einsendungen zu schützen.

Besonders leistungsstark wird das Plugin in Kombination mit dem Classic Add-On, das viele zusätzliche Funktionen und Formularelemente ergänzt. Formular-Aktionen wie E-Mail-Versand, Empfangsbestätigungen und die Integration in den Flow Builder ermöglichen es Ihnen, übermittelte Daten automatisch zu verarbeiten und in bestehende Shopware-Workflows einzubinden.

Dank seiner flexiblen Struktur kann das Plugin für unzählige Szenarien eingesetzt werden. Typische Beispiele sind Kontaktformulare, Widerrufsformulare, Bewerbungen, Produktanfragen, kundenspezifische Formulare und bestellbezogene Formulare. Übermittelte Formulardaten können außerdem in maschinenlesbaren Formaten wie Plaintext, HTML, XML und JSON bereitgestellt werden. Dadurch eignen sie sich ideal für die Weiterverarbeitung oder die Integration in externe Systeme.

## Datei-Upload

Die integrierte Datei-Upload-Funktion ermöglicht es Ihren Kunden, Dateien direkt über ein Formular zu übermitteln. Hochgeladene Dateien können als E-Mail-Anhang versendet oder direkt im Shopware Media Manager gespeichert werden. Dies ist für viele praktische Anwendungsfälle hilfreich, zum Beispiel für Bewerbungen, Supportanfragen, individuelle Produktanfragen, Dokumentenübermittlungen oder alle Prozesse, bei denen Kunden zusätzliche Dateien bereitstellen müssen.

## Datenbank-Kompatibilität

Formulardaten können Datenbankfeldern zugeordnet und strukturiert verarbeitet werden. Dadurch werden erweiterte Anwendungsfälle möglich, bei denen übermittelte Daten nicht nur per E-Mail versendet, sondern auch gespeichert, wiederverwendet oder an andere Systeme übertragen werden sollen. In Kombination mit den verfügbaren maschinenlesbaren Ausgabeformaten bietet das Plugin eine starke Grundlage für automatisierte Workflows und individuelle Integrationen.

Weitere Informationen finden Sie unter:
https://docs.moori.net/plugin/MoorlForms/how-tos/#datenbank-mit-formularen-befullen

## Entwickelt für Shopware 6

Das Plugin wurde exklusiv für Shopware 6 entwickelt und integriert sich direkt in die Shopware Administration und die Storefront. Es sind keine externen Iframe-Formulare erforderlich. Dadurch wird eine nahtlose Nutzererfahrung gewährleistet, und die Formularverwaltung bleibt vollständig innerhalb der Shopware-Umgebung.
