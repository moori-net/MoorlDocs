# Mehrere PDF Dokumente erzeugen

Select orders in the order overview and open “Create documents” to generate invoices and/or delivery notes. “Download originals as ZIP” downloads the unchanged original files in a ZIP archive, preserving embedded ZUGFeRD data and including XML documents. Existing documents are reused; missing documents are generated as with the PDF export.

The existing actions to open or download a merged PDF remain available. The merged PDF is intended for printing and does not retain embedded XML data.
