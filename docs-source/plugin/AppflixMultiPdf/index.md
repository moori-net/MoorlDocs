# Mehrere PDF Dokumente erzeugen

In der Bestellübersicht können Sie Bestellungen auswählen und über „Dokumente erstellen“ Rechnungen und/oder Lieferscheine erzeugen. Mit „Originale als ZIP herunterladen“ erhalten Sie die einzelnen Originaldateien unverändert in einem ZIP-Archiv. Eingebettete ZUGFeRD-Daten bleiben dabei erhalten; XML-Dokumente werden ebenfalls aufgenommen. Bereits vorhandene Belege werden wiederverwendet, fehlende Belege werden wie beim PDF-Export erstellt.

Die bisherigen Aktionen zum Öffnen und Herunterladen eines zusammengeführten PDFs stehen weiterhin zur Verfügung. Das Sammel-PDF ist zum Ausdrucken vorgesehen und übernimmt keine eingebetteten XML-Daten.

Die Plugins von Appflix sind das Resultat von geballtem Shopware Know-How in Front- und Backend. Entwickelt von moori und RH-Webdesign für ein perfektes Zusammenspiel aus Design und Funktionalität.
